# 💎 Diamond Price Prediction

Predicting the price of a diamond based on features like **carat, cut, clarity, color, depth, table, and dimensions (x, y, z)** using Machine Learning.

This project includes:
- A trained ML model  
- A complete training & prediction pipeline  
- A user-friendly web app built with **Streamlit**
